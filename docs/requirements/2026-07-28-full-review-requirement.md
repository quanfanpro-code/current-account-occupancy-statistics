## 背景与问题

对 `往来占用统计` 项目（Python + pandas + tkinter/customtkinter 桌面工具）做全量代码复核后发现：

1. **致命：`config.py` 编码损坏，程序完全无法启动。** 文件内 8 个中文字符串的最后一个 UTF-8 字节被替换为 `0x3F`（问号），整个文件不再是合法 UTF-8，且未声明编码。任何 `import config` 立即抛 `SyntaxError`。`gui.py`、`models.py`、`reporting.py` 均依赖 `config.py`，因此主程序与全部测试（5 个测试文件）都无法加载。实测 `pytest tests` 在收集阶段即失败。
2. **高风险：早于期初日期的交易被静默丢弃。** `pipeline.py` `calculate_balances` 中 `pivot.reindex(all_dates)` 的 `all_dates` 从期初日期开始，期初日期之前的交易会被 reindex 直接裁掉，余额结果错误且无任何提示。
3. **中风险：界面允许选择 `.xls` 文件，但读取固定 `engine="openpyxl"`，`.xls` 必然读取失败**，报错信息晦涩（openpyxl 不支持旧版 xls 格式）。
4. **中风险：全部结果表为空时导出必崩。** `excel_io.save_results` 的空兜底是 `("空表", pd.DataFrame())`，而 `make_excel.make_excel` 会跳过所有 empty DataFrame 且预先删光了 workbook 的默认 sheet，最终 `wb.save` 时 workbook 没有任何 sheet，抛 `IndexError`。
5. **文档与实际不符：** README 声称存在外层双击启动文件 `往来占用统计.py`，实际不存在；`config.py` 版本号 `v2.0.4` 与 README 的 `v2.0.5` 不一致。
